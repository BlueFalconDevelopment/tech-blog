Welcome! This is the first post on the blog, mostly here to prove the pipeline
works end to end: Markdown in `src/content/blog/`, rendered through a shared
layout, tagged, searchable, and syndicated over RSS.

A few things this blog scaffold gives you out of the box:

- **Content collections** for type-checked frontmatter (title, description,
  publish date, tags, optional hero image).
- **Tag pages** generated automatically from whatever tags you use.
- **RSS feed** at `/rss.xml`.
- **Full-text search** powered by [Pagefind](https://pagefind.app/), built at
  deploy time — no external service required.
- **Dark mode** with a manual toggle that respects system preference by
  default.
- **Auto-generated OG images** for social previews, one per post.
- **Comments** via [giscus](https://giscus.app/), backed by GitHub
  Discussions once you wire up a repo.

Delete this post whenever you're ready to publish something real.
